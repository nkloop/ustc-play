# 球场相见 · 微信小程序体验版

这是与 Web 原型并存的独立小程序工程。五个底部入口可切换首页、发现、我的状态、好友和我的；球场详情展示内置场地信息。收藏、关注、个人状态和昵称仅保存在当前微信客户端。

**当前未发布，也未连接腾讯云或其他服务器。** 场地描述、热度、上报次数、人数与好友资料均为内置演示数据，不应作为真实情况对外宣传或依赖。状态和关注操作只在本机生效，用户间不会同步。完整功能的服务类目及个人主体可用性仍需向微信平台确认；不能直接以「工具 → 信息查询」类目提交这个完整体验版审核。

## 在微信开发者工具中预览

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)并用小程序管理员或开发者微信登录。
2. 选择「导入项目」，项目目录选本文件夹 `miniprogram/`，项目类型选「小程序」。
3. `project.config.json` 已配置用户提供的 AppID `wx6877c93558f95532`。如果开发者工具提示无权限，请由管理员在微信公众平台将你的微信加入项目成员。
4. 导入成功后点击「编译」；可用模拟器体验，或点「预览」用微信扫码在手机体验。

不要在没有核对服务类目、备案要求、真实数据来源和隐私规则前提交正式审核。项目不包含 AppSecret，也不需要云资源或付款。

## 文件

- `data.js`：内置演示球场信息
- `components/bottom-nav/`：五入口底部导航
- `pages/index/`：运动切换和球场列表
- `pages/discover/`：浏览全部内置球场
- `pages/status/`：本机运动状态
- `pages/friends/`：模拟好友和本机关注
- `pages/profile/`：昵称、收藏和隐私开关
- `pages/detail/`：球场详情
- `project.config.json`：开发者工具项目配置
