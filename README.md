# U-Play · 球场相见

独立制作的校园运动信息网站，非中国科学技术大学官方服务。前端为 React + TypeScript + Vite，使用 CloudBase 身份认证和文档数据库。

网站：<https://ustc-play-dev-d4gwfhjz88eefeafa-1507774569.tcloudbaseapp.com/>

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
```

打开终端显示的地址（通常是 `http://localhost:5173`）。同一局域网中的手机可以打开电脑的局域网 IP 与端口预览；电脑和手机需要在同一网络下。

其他命令：

```bash
npm run check    # TypeScript 类型检查
npm run build    # 类型检查并构建 dist/
npm run preview  # 本地预览构建产物
```

## 当前数据与登录

- 游客可浏览静态球场目录；当前 CloudBase 文档数据库要求登录会话，实时上报和公开状态须登录后查看。
- 邮箱密码注册会先发送验证码，必须在网站验证码输入框完成确认；之后可用邮箱密码登录。
- 登录用户可提交球场热度和限时运动状态，数据保存在 `court_reports`、`play_status` 集合。没有真实上报时显示“暂无数据”。
- `court_reports` 使用公开读、创建者写的自定义规则；`play_status` 使用所有登录用户可读、创建者写的权限。前端只显示有效期内的记录。
- 昵称和收藏是本机浏览器偏好，不是云端资料；尚无真正的好友关系、服务端反刷、学校身份核验。
- 球场名称和位置是原型中的静态目录信息，尚未经过学校官方核验。没有内置模拟人数、热度或好友动态。

## 部署与验证边界

`src/cloudbase.ts` 中的 EnvId 已从 CloudBase 环境列表核对。不要把服务端密钥写进前端。`dist/` 需部署到 CloudBase 静态托管根目录。默认域名不需要购买；首次访问可能出现腾讯云风险提醒，点击继续访问才能进入网站。

静态构建和页面检查不能代替真人邮箱验证码、多账户权限测试。上线前应使用两个本人控制的邮箱测试注册、登录、状态提交、跨账户读取和禁止篡改。不要把未完成测试的流程标为已验证。

`miniprogram/` 是旧的微信小程序原型，仍是模拟数据，不能视为这套网站的正式客户端。
